# Room Manager • ห้อง 1/2

ระบบจัดการห้องแบบเว็บจริง: สมาชิก, ยศ, งานเวร, รายงาน, เงินห้องรายสัปดาห์, แชท และโปรไฟล์

## สิ่งที่มี

- Login / สมัครสมาชิกด้วย Supabase Auth
- เก็บข้อมูลออนไลน์ใน PostgreSQL
- RLS แยกข้อมูลตามห้อง
- ยศ: เจ้าของเว็บ / ผู้ช่วยพัฒนา / หัวหน้าห้อง / รองหัวหน้า / นักเรียน
- งานเวร: มอบหมาย, กำหนดวัน, ติ๊กเสร็จ
- รายงาน: ไม่กวาดห้อง / ไม่ทำเวร / หนีเวร / ไม่ถูพื้น / ไม่ทิ้งขยะ / อื่น ๆ
- ประวัติการถูกรายงานในโปรไฟล์
- เงินห้องรายสัปดาห์ + สถานะจ่าย/ค้าง
- แชทห้อง
- แก้ชื่อ, นามสกุล, เลขที่
- อัปโหลดรูปโปรไฟล์จากแกลเลอรีไป Supabase Storage
- ธีม ดำ / เทา / ขาว / ฟ้า-น้ำเงิน
- Responsive สำหรับมือถือ/แท็บเล็ต/คอม

## ติดตั้งให้ใช้งานจริง

1. สร้างโปรเจกต์ Supabase
2. เปิด SQL Editor แล้วรัน `supabase-schema.sql` ทั้งไฟล์
3. เปิด `index.html` แล้วใส่:
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
4. Deploy `index.html` ขึ้น GitHub Pages / Netlify / Cloudflare Pages
5. สมัครบัญชีแรก
6. ไปที่ Supabase > Authentication > Users แล้วเอา UUID ของบัญชีแรกไปตั้งเป็น owner:
   `update profiles set role='owner' where id='UUID';`

### หมายเหตุด้านความปลอดภัย

ห้ามใส่ `service_role` key ใน HTML เด็ดขาด ใช้เฉพาะ `anon` key เท่านั้น

ระบบใช้ RLS เพื่อไม่ให้ผู้ใช้ห้องอื่นอ่าน/แก้ข้อมูลห้องนี้ได้ และการเปลี่ยนยศถูกจำกัดไว้ที่ owner/developer

## ข้อจำกัดของ GitHub Pages

GitHub Pages เป็น static hosting จึงไม่สามารถเก็บฐานข้อมูลเองได้ ระบบนี้ใช้ Supabase เป็น backend/database/auth/storage ซึ่งเป็นส่วนที่ทำให้ข้อมูลยังอยู่แม้เปลี่ยนเครื่องหรือเปิดเว็บจากคนละอุปกรณ์
